# 🏮 大稻賭埕之夜｜Dadaocheng-Nights-Club

> *「夜幕低垂，霓虹初上。推開隱匿於迪化街老磚瓦深處的暗門，黑膠唱盤悠揚低迴，籌碼清脆碰撞——歡迎步入大稻賭埕。」*

---

### 🎲 賭埕九大攤位

#### 🏮【外場・夜市街頭懷舊】
* 🔴 **經典打彈珠**：黃銅釘板，蓄力手感，重現經典童年回憶。
* 🔺 **自由落體彈珠檯**：彈珠順流而下，挑戰極限百倍大獎。
* 🎲 **十八仔！**：經典小賭怡情遊戲，重現街頭豪氣叫陣。
* 🕹️ **不能沒有夾娃娃機**：精準操控，下爪考驗。

#### ♠️【內閣・地下俱樂部】
* 🎡 **賭場必備歐式輪盤**：紅黑輪盤飛旋，大獎落誰家？
* ♠️ **21點**：沉著應對，分牌雙倍，經典智慧博弈遊戲。
* 🃏 **德州撲克**：你來我往，暗潮洶湧，對手也不是省油的燈！
* 🎲 **花旗骰 (Craps)**：美式經典擲骰遊戲，感受全場洶湧的吶喊。
* 🍒 **不能沒有老虎機**：莫非777即將出場？

---

### 🎒 賭埕通行制度

* 🪙 **籌碼與彈珠全場通用**：籌碼彈珠帶著走，找到自己最擅長的遊戲。
* 🏆 **黑市當鋪密藏**：於各攤位達成隱藏成就或贏得大獎，將解鎖稀有珍品收錄於隨身行囊。
* 🎵 **DJ點唱機**：內建爵士與復古老台北氛圍曲目，隨時切換個人專屬微醺夜色。
* 📊 **賭神生涯**：忠實記錄各桌手數、下注流水與歷史勝率曲線。

---

### 🛎️ 全場通行手則

* **通用互動**：支援全桌面滑鼠直覺操作與點擊下注。
* **快捷輔助**：隨時按 `ESC` 關閉任何彈出視窗與對話面板。
* **離桌保證**：隨時換桌或返回大廳櫃檯，未派送之籌碼與收益皆完整結算。
