# 🏮 大稻賭埕之夜｜Dadaocheng-Nights-Club

> *「夜幕低垂，霓虹初上。推開隱匿於迪化街老磚瓦深處的暗門，黑膠唱盤悠揚低迴，籌碼清脆碰撞——歡迎步入大稻賭埕。」*

---

### 🎲 賭埕九大攤位

#### 🏮【外場・夜市街頭懷舊】
* 🔴 **黃銅打彈珠**：54 孔古典黃銅釘板，純粹手感蓄力翻越頂弧，挑戰風車穿梭與特獎孔。
* 🔺 **金字塔彈珠 (Plinko)**：多層排釘層層折射，彈珠順流而下，直奔最外側極限倍率槽。
* 🎲 **正宗十八仔**：青花瓷大碗公擲骰手氣交鋒，比對子拚點數，重現夜市最豪氣的叫陣。
* 🕹️ **復古夾娃娃機**：俯視精準操控機械天車，下爪考驗抓力重心，網羅大稻埕限定珍品。

#### ♠️【內閣・地下俱樂部】
* 🎡 **歐式單零輪盤**：象牙小球在 37 格紅黑輪盤上飛旋，完整歷史路單縱覽下注走勢。
* ♠️ **21點黑傑克**：沉著應對莊家明牌，分牌、雙倍下注決策分秒，純粹智慧博弈。
* 🃏 **德州撲克**：公共牌池暗潮洶湧，精準讀牌、加注威懾或果斷棄牌，爭奪全池榮耀。
* 🎲 **花旗雙骰 (Craps)**：美式經典擲骰狂歡，掌握過關線與賠率，感受全場沸騰心跳。
* 🍒 **水果拉霸機**：傳統滾輪手把拉動，霓虹彩燈旋轉閃爍，靜候 777 連線頭獎爆發。

### 🎒 賭埕通行制度

* 🪙 **籌碼通用制**：全場籌碼自由流通，隨桌帶著走；亦可隨時在櫃檯添購彈珠彈藥。
* 🏆 **黑市當鋪密藏**：於各攤位達成隱藏成就或贏得大獎，將解鎖稀有骨董珍品收錄於隨身行囊。
* 🎵 **隨身黑膠點唱**：內建爵士與復古老台北氛圍曲目，隨時切換個人專屬微醺夜色。
* 📊 **個人生涯流水**：忠實記錄各桌手數、下注流水與歷史勝率曲線。

---

### 🛎️ 全場通行手則

* **通用互動**：支援全桌面滑鼠直覺操作與點擊下注。
* **快捷輔助**：隨時按 `ESC` 關閉任何彈出視窗與對話面板。
* **離桌保證**：隨時換桌或返回大廳櫃檯，未派送之籌碼與收益皆完整結算。
